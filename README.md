# Jienice 图像档案

这是一个由 GitHub Pages 托管的响应式个人摄影档案。

## 添加照片

1. 将 `.jpg`、`.jpeg`、`.png`、`.webp` 或 `.avif` 文件放入 `public/archive/`。
2. 提交并推送到 `main` 分支。
3. GitHub Pages 会在构建时自动扫描目录，新照片无需手工加入页面数组。

页面不维护固定图片清单。推荐使用以下文件名格式：

```text
YYYY-MM-DD-tag[-tag...]-文件标识.jpg
```

- `YYYY-MM-DD` 会识别为完整日期；缩略图下仍只显示 `YYYY-MM`。
- 日期之后、最后一段之前的内容都会识别为标签，支持多个标签。
- 最后一段仅作为文件标识，不作为标签或可见信息展示。
- 标签内部需要空格时，可以使用下划线。
- 宽高由浏览器在图片加载后自动读取。
- 页面顶部按年份筛选；缩略图下仅显示年月。
- 打开大图后，标签与完整日期显示在图片下方。

例如，`2025-05-02-fxn-185753.394.jpg` 会识别日期 `2025-05-02`、标签 `fxn`；`185753.394` 仅是文件标识。

没有日期的文件名也支持相同的标签与文件标识结构。例如 `fxn-185753.394.jpg` 会识别标签 `fxn`，日期使用文件修改日期。旧的 `YYYY-MM-名称` 格式也会继续兼容。

例如：

```text
public/archive/
├── 2025-05-02-fxn-185753.394.jpg
└── fxn-185754.018.jpg
```

## 发布设置

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)

`index.html` 使用 GitHub Pages 内置的 Jekyll/Liquid 在构建时读取图片目录，因此不要添加 `.nojekyll`。
